## 玩法机制

这里模拟的是《无畏契约》中经典的"爆能器"博弈：进攻方部署爆能器后，防守方必须在 45 秒内完成拆除，否则爆能器引爆。

**启动动画**：开机后执行静默自检，屏幕显示 GIF 动画约 3 秒，同步播放启动音频。动画和音频结束后进入未部署状态。

**部署**：按住 KEY_UP，屏幕出现部署进度条。持续 4 秒后进度条填满，部署成功，45 秒倒计时开始。如果中途松手，部署取消——按住不到 1 秒就松的话，部署音效还会继续播到 1 秒，还原"假下包"机制。

**倒计时**：已部署状态下，播放 45 秒的已部署音效，红色 LED 随着音效的节奏逐渐加快。 屏幕上显示一条带中线的拆除进度条。

**拆除**：按住 KEY1，进入拆除状态。绿 LED 亮起，进度条从当前进度开始填充。如果之前从未拆到过半，需要用满 7 秒才能拆完。但如果某次按住超过了 3.5 秒（进度过半），松手后这 50% 就会被**永久锁定**——之后无论再失败多少次，50% 都在，下次再按只需 3.5 秒即可。进度条一旦填满 100%，即拆除成功。

**拆除成功**：停止倒计时，显示剩余时间。此后按 KEY0 即可播放随机彩蛋音效（开串！），再按切换到下一首。

**引爆**：如果 45 秒到还没拆完，屏幕上显示继续拆除仍需的时间（爆炸时未在拆除则不显示）。同样可以按 KEY0 触发另一类彩蛋。

**图片浏览**：在已拆除或已引爆状态下，按 KEY2 进入图片浏览模式，LCD 全屏显示 SD 卡中 PICS 目录下的 BMP 图片。KEY_UP/KEY1 上下翻页， KEY2 退出。浏览图片时彩蛋切歌不受影响。

## 外设连接方法

- **SD 卡**：插入开发板侧面的 Micro SD 卡槽，金属触点朝下。首次使用前需按上述结构存放文件
- **音箱/耳机**：将 3.5mm 插头插入开发板的 **PHONE** 口（注意不是 LINE_IN）。如使用带 USB 供电的音箱，USB 端接任意 5V 电源
- **电源**：开发板需 12V 1A 外接电源供电（4.3 寸屏功耗较大，USB 供电可能不足）

## 快速开始

1. **准备 SD 卡**：将一张 Micro SD 卡按上述文件结构放入所有音频、字库和图片文件，插入开发板卡槽
2. **连接设备**：PHONE 口插上耳机或音箱，接好 ST-LINK 烧录器和 12V 电源
3. **打开工程**：在 Keil uVision5 中打开 `USER/ValorantSpike.uvprojx`，编译器选 ARM Compiler v5
4. **编译烧录**：`Build` → `Download`，程序通过 ST-LINK 写入开发板
5. **上电运行**：按键复位，屏幕显示启动动画后进入主程序

## 程序特点

- **全非阻塞主循环**：LED 闪烁、LCD 刷新、音频喂流均在主循环中按系统节拍驱动，不使用阻塞延时
- **时间同步音频恢复**：拆除时短暂暂停 planted.mp3 后，根据倒计时已过时间按比例跳转文件偏移，确保音频始终与 45 秒倒计时画面同步
- **拆除进度永久锁定**：过半后的进度永不回退，松手再按只需接续剩余时间即可拆完
- **图片解码不中断音频**：通过 PICTURE 库的回调函数指针，解码间隙持续给 VS1053 喂数据
- **中文字库热更新**：开机时自动检测 SPI Flash 中的字库完整性，缺失则从 SD 卡静默恢复
- **状态图预加载**：8 张状态指示图在启动时从 SD 卡一次读入外部 SRAM，运行时切换零延迟

## 按键

| 按键 | 功能 |
|------|------|
| KEY_UP | 部署（按住 4 秒） |
| KEY1   | 拆除（按住累计 7 秒/半进度 3.5 秒阈值） |
| KEY0   | 彩蛋（首次播放 / 再次切歌） |
| KEY2   | 图片浏览（进入/退出） |
| KEY_UP | 浏览时：上一张 |
| KEY1   | 浏览时：下一张 |

> **注意**：KEY0 和 KEY2 是**松手触发**而非按下触发——按住不放不会有反应，松开瞬间才会执行对应操作。

## 注意事项

- **供电**：4.3 寸 LCD 功耗较大，请使用 12V 1A 外接电源，勿仅靠 USB 供电，否则可能白屏或花屏
- **首次启动**：如果 W25Q128 Flash 中尚无字库，首次上电会自动从 SD 卡更新，屏幕会显示更新进度条，约 5-10 秒
- **不可拔卡启动**：SD 卡必须插入后才能上电运行，否则卡在初始化阶段，屏幕显示 `SD: FAIL!`
- **图片格式**：PICS/ 目录下的图片浏览功能仅支持 BMP 格式。PNG 和 JPG 需预先转换为 BMP 放入
- **可选文件**：`startup.mp3`（启动音频）、`Easter_eggs/` 下的彩蛋 MP3 和 `spike_pics/*.bin` 缺失不会导致程序报错，对应功能静默跳过
- **音频输出**：全部音频从 **PHONE** 口输出。板载扬声器在本项目中保持静音

## 代码结构

```
APP/                 — 状态机、音频管理
USER/                — 程序入口、Keil 工程
HARDWARE/            — 外设驱动（LED/按键/LCD/VS1053/SD 卡/SRAM/SPI/W25QXX）
FATFS/               — FatFS 文件系统
TEXT/                — GBK 字库渲染与自动更新
PICTURE/             — BMP/GIF/JPEG 解码库
SYSTEM/              — 时钟、延时、串口
MALLOC/              — 内部+外部 SRAM 内存池
```
